# OCR 文字识别工具

基于 PyQt6 + RapidOCR（PP-OCRv6）的 Windows 桌面 OCR 工具，针对**代码截图**优化：保留缩进与空行、自动去行号、低置信度行高亮提醒，识别结果可直接编辑复制。

## 功能特性

- **三种导入方式**：打开图片 / 粘贴截图（Ctrl+V）/ 拖拽图片到窗口
- **代码模式**：保留缩进层级与空行、自动去除编辑器行号，等宽字体显示，代码粘贴即用
- **低置信度高亮**：置信度低于 0.85 的行自动黄色高亮 + 状态栏提示行号，方便人工核对
- **结果可编辑**：识别结果可直接修改，一键复制全部 / 保存为 TXT / 识别后自动复制到剪贴板
- **全离线运行**：模型内置，无需联网，不上传任何图片
- **单实例快速启动**：文件夹版约 2 秒启动

## 下载使用

到 [Releases](../../releases) 下载最新版：

| 版本 | 说明 |
|---|---|
| `OCRTool_V2.exe`（单文件版） | 免解压直接运行；每次启动需解压约 5 秒，方便分发 |
| 文件夹版 | 克隆源码后用 `app_dir.spec` 自行打包，启动约 2 秒，推荐日常使用 |

支持 Windows 10 / 11，无需安装任何运行库。

## 从源码运行

```bash
pip install -r requirements.txt
python app.py
```

也可以直接把图片路径作为参数传入（右键图片 → 打开方式），自动加载并识别：

```bash
python app.py 截图.png
```

## 打包

```bash
# 文件夹版（启动快）
pyinstaller app_dir.spec --noconfirm --clean

# 单文件版
pyinstaller app.spec --noconfirm --clean
```

产物输出到 `dist/`。版本号由 `app.py` 中的 `APP_VERSION` 统一控制，打包脚本自动读取，产物名自动带 `_V..` 后缀（升级版本只改这一处）。

打包后可用自检模式验证：

```bash
OCR文字识别_V2.exe --selftest 图片.png 输出.txt
```

## 技术栈

- **界面**：PyQt6（强制浅色调色板，避免 Windows 深色模式下文字白字白底）
- **OCR**：RapidOCR 3.x（PP-OCRv6 det + rec 模型，ONNX Runtime CPU 推理）
- **文本重建**：按坐标归行 → 缩进还原（CJK 宽度折算）→ 空行检测 → 全角标点修正

## 已知限制

- 深色主题下**对比度极低**的字形（如暗灰色 `__name__` 这类极细笔画）无法完全识别，这类行会被黄色高亮提示；
- 识别表格/文档截图时建议**取消勾选「代码模式」**，否则缩进还原会产生多余空白；
- 首字符为全角符号的情境（如 `（`）在纯中文语境中保持全角，属预期行为。
